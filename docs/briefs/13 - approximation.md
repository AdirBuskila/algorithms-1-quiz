# אלגוריתמי קירוב

## מה המבחן שואל
שאלות בונוס, בדרך כלל על כיסוי קודקודים:
- איזו קבוצה **יכולה** להתקבל מהרצת אלגוריתם הקירוב על גרף נתון (22A-A שאלה 5, `22A-A-Q5`).
- הרצה בטבלה: ערכי $C$ ו-$E'$ בכל איטרציה (22A-C שאלה 5, `22A-C-Q5`).
- הפיכת בעיה לכיסוי קודקודים והפעלת הקירוב, עם יחס הקירוב (23A-B שאלה 5, `23A-B-Q5`).
- קירוב $\Theta(\log n)$ לכיסוי קבוצות (23A-A שאלה 5, `23A-A-Q5`).

## הגדרות
בבעיות מינימום קשות (NP-קשות), אלגוריתם **קירוב** רץ בזמן פולינומי ומחזיר פתרון חוקי שעלותו קרובה לאופטימום. הוא בעל **יחס קירוב** $\rho$ אם לכל קלט עלות הפלט היא לכל היותר $\rho\cdot OPT$.
- **כיסוי קודקודים:** קבוצה $C\subseteq V$ כך שכל צלע נוגעת לפחות בקודקוד אחד של $C$. מחפשים את הקטנה ביותר.
- **כיסוי קבוצות:** נתון עולם $U$ ואוסף קבוצות שאיחודן $U$. בוחרים כמה שפחות קבוצות שאיחודן $U$.

## אלגוריתם הקירוב לכיסוי קודקודים (יחס 2)
```
C <- {} ; E' <- E
while E' is not empty
    pick any edge (u, v) in E'
    C <- C + {u, v}
    delete from E' every edge that touches u or v
return C
```
הזמן $O(|V|+|E|)$ ברשימות סמיכויות. הבחירה "צלע כלשהי" פירושה שאפשר להגיע לפלטים שונים לפי סדר הבחירה.
- **פלט חוקי:** האלגוריתם עוצר רק כשאין צלע שלא כוסתה.
- **יחס 2:** הצלעות שנבחרו $M$ הן **זיווג** (אין להן קודקוד משותף, כי אחרי כל בחירה כל צלע שנוגעת בקצותיה נמחקת). כל כיסוי חייב להכיל קודקוד אחד לפחות מכל צלע של $M$, וקצוות של צלעות שונות שונים, ולכן $OPT\ge|M|$. מצד שני $|C|=2|M|$, כלומר $|C|\le 2\cdot OPT$.
- **הדוקות:** לצלע בודדת $|C|=2$ ו-$OPT=1$. גם כשבוחרים זיווג מושלם ב-$K_{3,3}$: $|C|=6$ ו-$OPT=3$.

**איזו קבוצה יכולה להיות הפלט?** (`22A-A-Q5`) פלט הוא תמיד קבוצת הקצוות של זיווג **מקסימלי** (אי אפשר להוסיף לו צלע). לכן קבוצה $C$ היא פלט אפשרי אם ורק אם:
1. $C$ היא כיסוי קודקודים (כל צלע נוגעת בה), ו-
2. בגרף המושרה על $C$ יש זיווג מושלם (בפרט $|C|$ זוגי).

בדיקה מעשית של כל אפשרות: (א) האם יש צלע ששני קצותיה מחוץ ל-$C$ (אז לא כיסוי)? (ב) האם $|C|$ זוגי? (ג) קודקוד עם שכן יחיד ב-$C$ **מחייב** את השכן שלו להיות ב-$C$ (כי אפשר לצרף אותו רק לשכנו), ואם השכן חסר, הקבוצה אינה פלט אפשרי. (ד) מחפשים זיווג מושלם בתוך $C$. יתכנו כמה קבוצות נכונות, ואז מסמנים את כולן.

**הרצה בטבלה** (`22A-C-Q5`): בגרף עם $15$ צלעות ו-$10$ קודקודים $a,\dots,j$, אחת ההרצות האפשריות:

| איטרציה | צלע | $C$ | $E'$ |
|---|---|---|---|
| 1 | $(a,b)$ | $\{a,b\}$ | $\{hg,gf,ih,id,cd,de,gd,dj,jf,fe\}$ |
| 2 | $(h,g)$ | $\{a,b,g,h\}$ | $\{id,cd,de,dj,jf,fe\}$ |
| 3 | $(i,d)$ | $\{a,b,d,g,h,i\}$ | $\{jf,fe\}$ |
| 4 | $(f,e)$ | $\{a,b,d,e,f,g,h,i\}$ | $\emptyset$ |

באיטרציה הראשונה נמחקות $ab,ah,af,bi,bc$; בשנייה $hg,gf,ih,gd$; בשלישית $id,cd,de,dj$; ברביעית $fe,jf$. הפלט $8$ קודקודים, והאופטימום בגרף הזה $4$: היחס $2$ בדיוק. כל בחירה אחרת של צלעות היא הרצה נכונה אחרת.

## כיסוי קבוצות: חמדן (`23A-A-Q5`)
```
C <- U ; T <- {}
while C is not empty
    pick the set A that maximises |A intersect C|
    T <- T + {A} ; C <- C minus A
return T
```
**חוקיות:** כל עוד $C\ne\emptyset$ יש קבוצה שמכסה איבר חדש, ולכן האלגוריתם מסתיים אחרי לכל היותר $\min(m,n)$ סיבובים ומחזיר כיסוי.
**יחס $O(\log n)$:** יהי $k$ גודל הכיסוי האופטימלי. בכל בחירה נותנים לכל איבר שכוסה עכשיו "מחיר" $\tfrac1{|A\cap C|}$, כך שהמחיר הכולל שווה למספר הקבוצות שנבחרו. כשנותרו $r$ איברים לא מכוסים, $k$ הקבוצות האופטימליות מכסות אותם, ולכן יש קבוצה שמכסה לפחות $r/k$ מהם. החמדן בוחר קבוצה טובה לפחות כמוה, ומחיר כל איבר ברגע הכיסוי לכל היותר $\tfrac kr$. האיבר ה-$t$ מכוסה כשנותרו לפחות $n-t+1$ איברים, ולכן
$$|T|\le k\sum_{t=1}^{n}\frac{1}{n-t+1}=k\,H(n)\le k\,(\ln n+1)$$
כאשר $H(n)=1+\tfrac12+\dots+\tfrac1n$ הוא המספר ההרמוני. החסם הדוק עד כדי קבוע: אפשר לבנות קלט שבו $OPT=2$ והחמדן בוחר $\Theta(\log n)$ קבוצות (שתי שורות של איברים, וגושים בגדלים $2,4,8,\dots,2^t$ שחצי מכל גוש בכל שורה: החמדן לוקח את הגושים, ואילו שתי השורות מכסות הכול).

## הפיכת בעיה לכיסוי קודקודים (`23A-B-Q5`)
כדי להשתיל תוכנה אצל כמה שפחות אנשים כך שכל שיחה בין חברי הקבוצה תוקלט: בונים גרף שבו כל אדם הוא קודקוד וכל שיחה בין $x$ ל-$y$ היא צלע $(x,y)$. קבוצה של אנשים שאצלם משתילים היא **כיסוי קודקודים** (כל שיחה נוגעת באחד מהם). מריצים את אלגוריתם הקירוב ומחזירים את גודל הקבוצה. יחס הקירוב $2$.
> 🪤 הפתרון הרשמי מדגיש: זו אינה בעיית כיסוי קבוצות, ואסור לבחור בכל איטרציה את האדם בעל מספר השיחות הגדול ביותר (דרגה מקסימלית), כי לאלגוריתם כזה יחס הקירוב אינו חסום. בוחרים **צלע** ולוקחים את שני קצותיה.

## מלכודות נפוצות
> 🪤 בוחרים קודקוד במקום צלע, או לוקחים רק קצה אחד של הצלע. אז היחס 2 לא מובטח.

> 🪤 מחשבים רק את גודל הפלט ושוכחים לבדוק שהוא כיסוי חוקי.

> 🪤 אומרים "היחס הוא 2" בלי הנימוק: זיווג, $OPT\ge|M|$ ו-$|C|=2|M|$.

> 🪤 בהרצה בטבלה: מוחקים מ-$E'$ את כל הצלעות שנוגעות **באחד** משני הקצוות, לא רק את הצלע שנבחרה.

> 🪤 הקירוב ההרמוני לכיסוי קבוצות הוא $\ln n$ ולא קבוע, בניגוד לכיסוי קודקודים.

## דוגמה פתורה
מסלול $a-b-c-d$ עם הצלעות $ab,bc,cd$. אם האלגוריתם בוחר קודם $(b,c)$, נמחקות כל הצלעות, ו-$C=\{b,c\}$ בגודל $2$, והוא האופטימום. אם הוא בוחר קודם $(a,b)$ (נמחקות $ab,bc$) ואחר כך $(c,d)$, מתקבל $C=\{a,b,c,d\}$ בגודל $4=2\cdot OPT$. שתי התוצאות הן פלטים אפשריים: $\{a,b,c,d\}$ הוא כיסוי ובגרף המושרה עליו יש זיווג מושלם $\{ab,cd\}$, וגם $\{b,c\}$ הוא כיסוי עם זיווג מושלם $\{bc\}$. לעומת זאת $\{a,b,c\}$ אינו פלט אפשרי, כי גודלו אי-זוגי.
